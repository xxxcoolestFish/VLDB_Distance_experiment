# 新 Baseline 实验结果

**日期**: 2026-06-25
**数据**: Chengdu 111K nodes, random_500k queries
**方法**: r=2,s=62 L1Tilde, GNN=SAGE, 30ep

---

## DLGNN-style: DistanceEnhancedGNN

Anchor 距离特征(16个随机anchor) + GNN → concat → MLP → L1/L1Tilde

| 实验 | 配置 | Test MRE |
|:---:|------|:---:|
| 1 | 原版 SAGE Bi-Encoder（复用已有结果） | **3.77%** |
| 2 | SAGE + 16 anchor feat + MLP + L1 | 7.17% |
| 3 | SAGE + 16 anchor feat + MLP + L1Tilde(r=2,s=62) | **6.23%** |

L1Tilde Δ vs L1: **-0.94pp** ✅

---

## PSGNN-style: PositionSensingGNN

可学习 anchor 权重(16个anchor, softmax归一化) + GNN → concat → MLP → L1/L1Tilde

| 实验 | 配置 | Test MRE |
|:---:|------|:---:|
| 1 | 原版 SAGE Bi-Encoder（复用已有结果） | **3.77%** |
| 2 | SAGE + 16 learnable anchor + MLP + L1 | 8.54% |
| 3 | SAGE + 16 learnable anchor + MLP + L1Tilde(r=2,s=62) | **6.99%** |

L1Tilde Δ vs L1: **-1.55pp** ✅

---

## 与原始 CE 方法对比

| Baseline | 实验2 MLP+L1 | 实验3 MLP+L1Tilde | L1Tilde Δ |
|------|:---:|:---:|:---:|
| **DLGNN-style (anchor距离)** | 7.17% | **6.23%** | **-0.94** |
| **PSGNN-style (可学习anchor)** | 8.54% | **6.99%** | **-1.55** |
| SAGE CE（无anchor, 对照） | 9.31% | 8.14% | -1.17 |

---

## 核心结论

1. **Anchor 距离特征对 CE 有帮助**：DLGNN 6.23% / PSGNN 6.99%，均优于纯 CE 8.14%
2. **固定随机 anchor (DLGNN) 略优于可学习 anchor 权重 (PSGNN)**：6.23% vs 6.99%
3. **L1Tilde 在两个新 baseline 中均击败 L1**（-0.94pp, -1.55pp）
4. **但都不如原版 Bi-Encoder 3.77%**（差距约 2x）
